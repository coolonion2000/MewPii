# @ 文件和目录引用（第一版）

在输入框中输入 `@` 或 `看下 @文件名`，选择当前工作区的文件/目录。支持文件名、相对路径、中文及字符顺序模糊匹配；不支持拼音搜索。方向键切换候选，Enter/Tab 选择，Esc 关闭。邮箱地址不会触发；未选中的 `@文字` 按普通文本发送。

选中内容作为可移除标签保存。点击标签查看完整路径；文件可打开既有预览面板，目录仅展示路径。发送时附加 `<workspace-references>` JSON 路径清单，聊天消息将其显示为引用标签。不会自动读取整个文件，也不会提升文件访问权限；模型仍按需调用现有工具。引用草稿随会话保存，发送失败时恢复。

## 边界

- 仅文件和目录，不包括会话引用或 agent 分派。
- 使用当前 Conversation 的机器与工作区；断开的远程机器不会回落到本地搜索。
- `/api/files?mode=mention` 沿用现有工作区信任校验；不返回文件内容。
- 默认跳过隐藏文件/目录、依赖目录、构建产物和符号链接。候选最多 24 个，正常选择最多 24 项。
- 输入防抖 180ms，取消旧请求；索引缓存 10 秒、最多 8 个工作区/范围。新增文件可能稍后才进入结果。
- 单次索引最多检查 10,000 个目录项，检查点时间预算 750ms，深度上限 25。受文件系统单次操作耗时影响，这不是整个请求的硬实时上限。结果截断会提示；输入实际目录前缀（例如 `src/components/comp`）可缩小扫描范围。
- 搜索接口需要更新对应本地/远程服务后生效；旧服务会显示明确的更新提示，不把旧接口结果当成模糊搜索结果。

## 验证

`npm run test -w web` 覆盖触发位置、邮箱排除、路径序列化、草稿隔离及失败恢复。

`npm run build -w server && node --test server/test/file-mentions.test.mjs server/test/workspace-files.test.mjs` 覆盖模糊排序、结果上限、目录过滤、符号链接隔离与文件接口。

浏览器交互测试见 `web/test/browser/README.md`。远程路由和键盘遮挡在隔离夹具中验证，不等同于真实远程部署或手机输入法验收。
